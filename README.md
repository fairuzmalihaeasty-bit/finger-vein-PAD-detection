# Finger-Vein Presentation Attack Detection (PAD)

## Project Overview
This project explores presentation attack detection (PAD) using finger-vein biometric images.

## Current Progress
- Inspected the SCUT dataset folder structure.
- Counted real and spoof images across predefined splits.
- Visualized image counts for the full and ROI representations.
- Started inspecting sample images.

## Dataset
The project uses the SCUT finger-vein dataset.
Dataset files are not included in this repository.

## Planned Work
- Inspect image dimensions, formats, and color modes.
- Review the subject-independent five-fold cross-validation protocol.
- Implement a baseline k-nearest neighbours classifier.
- Evaluate reduced real-data training.
- Explore experiments using synthetic genuine and attack samples.
